# Customer-Churn-Python-Analysis
Customer churn analysis using Python to identify churn patterns, key drivers, and retention insights through EDA and data modeling.
This project analyzes customer churn data to understand why customers leave a company and how churn can be reduced. Using Python, the project performs end-to-end data cleaning, exploratory data analysis (EDA), and insight generation. The goal is to identify key churn drivers such as contract type, monthly charges, tenure, customer demographics, and service usage patterns. This project demonstrates strong analytical skills, data handling, visualization, and business understanding.

🎯 Key Insights Generated

Identified high-risk churn groups (high monthly charges, short tenure, month-to-month contracts).

Observed specific services that increase churn likelihood.

Found that long-term contract customers churn less.

Derived customer segments for targeted retention strategies.

Visualized churn patterns across demographics and service types.

Highlighted billing and contract features strongly tied to churn.
